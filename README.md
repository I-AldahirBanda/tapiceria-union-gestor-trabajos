# tapiceria-union-gestor-trabajos
Sistema básico en Java para la gestión de trabajos en la Tapicería “UNIÓN”. Permite registrar, listar, actualizar y eliminar pedidos, así como guardar y cargar información desde archivos de texto. Proyecto desarrollado con fines académicos, integrando control de versiones, gestión de tareas en Trello y pruebas automatizadas con JUnit.
